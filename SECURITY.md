# Security Policy

## Supported version

Only the newest release listed in this repository is supported during the early preview.

## Verify downloads

Download Liana only from this repository's Releases page and compare the archive SHA-256 with
`SHA256SUMS.txt`. This preview is not Apple-notarized, so macOS cannot provide the normal notarization
trust signal yet.

## Report a vulnerability

Use GitHub's private vulnerability reporting flow under the repository's **Security** tab. Do not put
API keys, credentials, private dictated content, recordings, or unredacted logs in a public Issue.

For ordinary reproducible bugs that contain no private data, use the bug-report Issue template.
