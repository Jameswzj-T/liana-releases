# Liana 0.1.0 RC3 · Early Preview

这是 Liana 的第一个公开早期预览候选，目的是验证真实用户能否安装、持续使用并愿意反馈。

## 本版包含

- Apple Silicon、macOS 14+ 的便携安装包；
- 默认本地 Qwen3-ASR 0.6B 听写；
- 全局热键、自动落字、确定性清理、个人拼写与纠正规则；
- 本机历史、原始转写查看和恢复；
- 用户主动开启的高准确云端转写；
- 用户主动开启、使用自有 Key 的自动整理与选中文字增强。

## 安全与安装提醒

本候选经过临时签名，但尚未使用 Apple Developer ID 签名，也未经过苹果公证。macOS 可能阻止
首次启动。只有在安装包来自本仓库且 SHA-256 与 `SHA256SUMS.txt` 一致时，才应按照
[安装说明](https://github.com/Jameswzj-T/liana-releases/blob/main/INSTALL.md)中的步骤选择“仍要打开”。

## 构建验证

这个候选对应的发布闸记录包括：Python 受跟踪核心测试 859 条、完整 brain 测试 861 条、Swift
测试 36 条，以及依赖、模型哈希、许可证、Mach-O 架构、深层临时签名和包内离线推理检查。

这些机械检查通过不等于已经完成苹果公证、另一台 Mac 首次安装或大规模真人验收。

## 已知限制

- 未经 Apple Developer ID 签名和公证；
- 只支持 Apple Silicon；
- 没有自动更新；
- 部分应用的光标与权限行为仍可能不同；
- 云端服务需要用户自己的 API Key，并可能由第三方产生费用。

反馈前请先脱敏，不要在公开 Issue 中附上 API Key、私人听写正文、录音或完整日志。
