# Liana 0.1.0 RC6 — Shortcut recovery and voiceprint

**Free open-source preview · Apple Silicon · macOS 26+**

Download `Liana-0.1.0-rc.6-macos-arm64.zip` and `SHA256SUMS.txt` from **Assets**. The automatically generated “Source code” archives are not ready-to-run apps. See the [installation guide](https://github.com/Jameswzj-T/liana-releases/blob/main/INSTALL.md).

## What changed

- Shortcut recovery: stale observed key presses no longer block right-side taps indefinitely after a missed release. Focus/session changes cancel unfinished taps; Accessibility state changes or failed monitor registration reinstall the listeners.
- Recovery uses an event-time boundary, so delayed keyboard combinations cannot be reinterpreted as standalone taps. A tap interrupted by recovery may be discarded; the next fresh complete tap can be used.
- The optional local CAM++ voiceprint model and its Apache-2.0 license are now bundled. The model was missing from RC5, which caused “Unavailable in this build”.
- Packaging now verifies the speaker model's hash and performs real model loading, synthetic embedding and temporary enrollment checks before producing the archive.

Default shortcuts remain **Right Command** to start/stop dictation and **Right Option** for the selected-text rewrite panel. Tap rather than hold. Saved custom shortcuts are preserved. The ASR model, text-cleanup prompt, list-formatting behavior and Keychain implementation are unchanged from RC5. Cloud features remain optional; saving a key does not enable them, and third-party charges apply only to requests you explicitly enable or test.

**Existing voiceprint users:** if you previously enrolled your voice and enabled **Only my voice**, that filter becomes active again now that its model is present. Review the switch in Settings if you want unfiltered dictation. Existing enrollment is retained; the update does not copy anyone else's enrollment. Voiceprint filtering is not identity authentication.

## Checks and limits

Passed: **65 Swift tests and 45 offline Python tests**, source checks, runtime relocation, fixed model hashes, native-library audit, individual native and complete App signature checks, ZIP integrity and package privacy checks. The final ZIP was extracted and its own Python successfully transcribed a fixed generated sentence, loaded the bundled voiceprint model and completed a temporary enrollment round-trip and same-signal comparison, with network access blocked. No real recordings, saved voiceprints, API keys or cloud calls were used for these checks.

These checks do **not** establish physical-keyboard, microphone-to-editor, first-install Accessibility/Keychain, broad multi-Mac or real-speaker filtering acceptance for this exact artifact. RC5's earlier generated-system-event results are not presented as new RC6 evidence. The recovery defects have targeted regression coverage; the exact cause of every previously reported “restart required” incident was not established. Please test installation and ordinary use on your Mac.

This remains an **ad-hoc signed, unnotarized preview** with no Apple Developer ID signature and no automatic updater. New builds may request app-specific Accessibility or Keychain authorization again. Do not disable system protection globally or delete saved keys as a workaround. Quit the old Liana before replacing it in Applications and launching RC6; retain the previous ZIP for rollback rather than running multiple copies.
