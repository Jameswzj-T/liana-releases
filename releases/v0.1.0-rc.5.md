# Liana 0.1.0 RC5 — Tap to dictate

**Free open-source preview · Apple Silicon · macOS 26+**

Tap **Right Command** once to start speaking, then tap again to finish and insert text. **Right Option** opens the selected-text rewrite panel. These are new-install defaults; saved custom shortcuts are retained. No holding is required.

Download `Liana-0.1.0-rc.5-macos-arm64.zip` and `SHA256SUMS.txt` from **Assets**. GitHub's automatically generated “Source code” archives are not ready-to-run apps. Follow the [installation guide](https://github.com/Jameswzj-T/liana-releases/blob/main/INSTALL.md) for file verification, first launch, and permissions.

[Watch the 19-second demo](https://github.com/user-attachments/assets/9330a221-150c-465d-ac24-d872f1cf6475). This is an edited walkthrough with AI-generated narration, not a real-time performance benchmark.

## What changed

- New default shortcuts: Right Command for dictation, Right Option for selected-text rewriting. Both remain configurable.
- Standalone right-side modifier keys trigger on release. Keyboard and mouse combinations cancel a pending tap; common shortcuts are not consumed by Liana.
- Repeated starts and cancelled microphone-permission waits cannot start an obsolete recording request later.
- Updated instructions, illustration, and short demo to show tap-to-toggle operation.

The speech model, text-cleanup prompt, accepted list-formatting behavior, and Keychain implementation are unchanged from RC4. Local dictation needs no account or API key. Cloud recognition and text features remain optional, off on a fresh installation, and require your own provider key; third-party charges may apply. Select text before using Right Option, then review and approve any rewrite before replacement.

## Checks and limits

Passed: 37 synthetic Python tests, 55 Swift tests, runtime/model/relocation checks, individual native and complete bundle signatures, ZIP integrity, and package privacy checks. A fixed generated speech sample was transcribed correctly with network attempts blocked, both in the assembled App and after extraction of the final ZIP.

On one development Mac, 20 generated-system-event checks passed through AppKit's local/global monitors: right-side taps, common key combinations, release recovery, and Command+Tab switching. These were counting probes using the product's hotkey code, **not** physical-keyboard, microphone, or complete dictation-to-editor acceptance tests. Simultaneous left/right modifier tests were covered by unit tests; a system run of those unusual gestures stopped when focus moved to another application. The cause of that focus change was not confirmed, and that system case is not claimed as passed. If another app uses the same shortcut, change Liana's shortcut in Settings.

This is an **ad-hoc signed, unnotarized preview**, without an Apple Developer ID signature. Apple Silicon and **macOS 26+** are required by the bundled runtime. New builds may request Accessibility or Keychain authorization again. Existing settings, history, and cloud switches are preserved. There is no automatic updater, and this exact package has not completed broad clean-device or multi-Mac acceptance. Never disable system protection globally to install it.
