# Liana 0.1.0 RC4 — local release preparation

**Status: local candidate only, not uploaded.** The existing RC3 release remains available and unchanged.

## Included

- Product source and synthetic offline tests now live alongside this repository's existing release history and illustrations.
- Local-first Qwen3-ASR 0.6B dictation, optional cloud transcription, automatic cleanup, selected-text rewriting, and history refinement.
- The accepted conservative list-formatting behavior is retained; mixed ordinal labels without explicit separator punctuation are not forced into a uniform style.
- Keychain authorization and explicit provider connection tests are presented as separate operations. Saving/testing a key does not enable cloud dictation features.
- The package is rebuilt from the committed public source; private development history and user data are excluded.

## Requirements and limitations

- Apple Silicon, **macOS 26 or later**, due to the locked MLX runtime. The Swift shell's older deployment target is not the complete runtime requirement.
- Ad-hoc signed preview only. **No Apple Developer ID signature or Apple notarization.**
- New builds can request Accessibility or Keychain authorization again. Existing settings/history are shared, so cloud switches may remain enabled for existing users.
- No automatic updater. The candidate is not yet accepted for clean-device installation, microphone input, or system authorization.
- Automated offline tests are not evidence of perfect transcription or semantic quality.

Final artifact hashes and the exact source commit are recorded beside the local ZIP. Upload only the reviewed ZIP and its checksum file, not build logs, isolated test homes, or audit reports. This page does not assert that RC4 is already downloadable.
