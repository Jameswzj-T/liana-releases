# Liana 0.1.0

The first fixed release of Liana: local dictation for Apple Silicon Macs running macOS 26+, with optional cloud transcription and text tools. The feature set is frozen; engineering diagnostic hosts and later experimental vocabulary/history candidates are excluded.

Download `Liana-0.1.0-macos-arm64.zip` and `SHA256SUMS.txt` under **Assets**. Verify the checksum, then follow [Installation](../INSTALL.md). The download includes the speech model, VAD, optional voiceprint model, Python runtime, and third-party licenses. Source is MIT-licensed; optional providers require your own keys and may charge separately.

## Changes from RC6

- Retains RC7 recovery for lost hotkey releases during idle periods.
- Repairs release checking after an externally cancelled modifier tap; recovery clears stale state without triggering recording by itself.
- Selected-text preview now offers **Copy candidate**. Confirm the selection and paste manually in your editor. It does not automatically replace text in another app, because selection changes could previously cause an unintended append or replacement. Copying replaces the clipboard contents.
- Version 0.1.0, public build 8. Recognition models, cloud providers/models, settings domain, Keychain identifiers, and history format are unchanged from the RC7 core.

## Verification and limits

Release checks cover synthetic offline Swift/Python regressions, locked dependency/model checksums, bundled interpreter relocation, native library paths, ad-hoc signatures, ZIP integrity, and private-file exclusion. Local models are exercised with generated speech/signals, without a microphone or paid API call. The release's verification summary records actual results.

This artifact has not completed a clean-device first install, system-permission acceptance, physical keyboard acceptance, or multi-editor microphone dictation test. Earlier engineering GUI results do not certify this binary. No accuracy percentage or model-quality guarantee is claimed. Names, numbers, relative times, quotations, mixed languages, and corrections can need manual checking. Cloud tools are off on a new installation; existing installations retain their switches.

The app is **ad-hoc signed, without Apple Developer ID signing or Apple notarization**. macOS may block first launch. Use Apple's per-app approval flow only if you trust it; never disable system security globally. No Intel build or automatic updater.

## Update and rollback

Quit Liana when no recording or unfinished work remains, retain the previous app/ZIP, and replace only `Liana.app`. Do not delete data or Keychain entries. The existing settings/data namespace and schema remain; this is not an isolated profile. Signing changes can require normal system authorization by you.

For rollback, quit and restore your previous app or [RC6](https://github.com/Jameswzj-T/liana-releases/releases/tag/v0.1.0-rc.6). The release process does not replace existing data. History is not a document backup; disk errors can prevent persistence. To uninstall, quit and move the app to Trash; local data and Keychain entries remain.
