# Liana

面向 Apple Silicon Mac 的本地优先语音输入工具：点一下右侧Command开始说话，再点一下结束并转写，文字输入到光标所在位置。

默认使用本地 Qwen3-ASR 0.6B。云端转写、自动润色和选中文字改写是分别控制的可选功能，需要自行配置服务商 Key，可能产生费用。

## 当前提供什么

- Swift 菜单栏应用、热键、录音与文本粘贴。
- 独立 Python 转写与文本处理模块。
- 本地转写、基础清洗、段落和明确列表的排版。
- 可选云端转写、自动润色、历史中的再次润色，以及选中文字后发出改写指令。
- Key 存在 macOS 钥匙串；原始转写可用于核对润色结果。

本仓库同时提供产品源码和[RC5 预览安装包](https://github.com/Jameswzj-T/liana-releases/releases/tag/v0.1.0-rc.5)。开源路线不要求购买苹果开发者会员；安装包采用临时签名，没有 Developer ID 签名和 Apple 公证，首次打开可能被系统拦截，见[安装说明](../INSTALL.md)。源码编译成功不等于所有机器的安装与权限行为均已验证。

## 从源码开始

当前锁定依赖的构建路线需要 Apple Silicon、macOS 26 或更新系统、支持 Swift 6 的 Xcode 工具链，以及 Python 3.12。Swift 外壳的最低声明为 macOS 14，但本次锁定的 MLX 运行库要求 macOS 26，不能把外壳声明当成整套产品的兼容范围。模型和 Python 依赖不在仓库内，首次准备需要下载。

请先阅读 [构建与运行](BUILDING.md)。构建、离线测试不会调用付费模型；下载模型和依赖是独立的联网步骤。

默认快捷键可在设置中修改：听写 `右⌘`，选区增强 `右⌥`，修改上一条 `⌘⇧U`。已保存的自定义快捷键保留。运行时需要麦克风与辅助功能权限。请先在空白文本编辑器中试用，不要直接向聊天窗口发送测试文字。

## 本地与云端

不开云端也能听写。开启云端转写会上传音频；开启自动润色会发送转写文字；选区改写会发送选中文字和改写指令。设置中的 Key 与功能开关相互独立。

“保存并测试”或服务测试按钮会发送固定测试文字或一秒静音音频，可能产生少量费用，但不会开启云端功能。单纯本地授权/读取钥匙串不等于调用云服务。

详细数据范围见 [隐私说明](PRIVACY.md)。请勿在公开 Issue 中粘贴 Key、录音、完整历史或诊断日志。

## 能力边界

语音识别与润色都可能出错；人名、数字、否定和重要信息请核对。自动排版不是严格文档编辑器，也不承诺任意语速、措辞都得到同一格式。明确列表可分行；没有分隔标点的混合序号不强制统一。关闭润色时不会获得云端润色效果。

当前公开构建路线仅覆盖 Qwen3-ASR 0.6B 与 Silero VAD。源码仍保留其他实验/备用入口，它们不属于这份构建说明支持的运行配置。

## 开发与贡献

执行 `bash build.sh check` 运行纯离线的源文件检查、Python 合成测试和 Swift 测试；执行 `bash build.sh build` 仅编译应用。测试通过不等同于真实麦克风、钥匙串授权、模型效果或跨设备验收。
