# 隐私与网络说明

## 默认本地处理

新用户默认使用本地转写。模型准备阶段需要下载文件；模型准备完成后，默认听写路线不需要把音频发送给云端服务。不能因此把所有可选功能称为“永不联网”。

## 用户主动开启的网络功能

| 功能 | 发给所选服务商的内容 |
| --- | --- |
| 云端转写 | 音频，以及该路线启用的词汇/上下文提示 |
| 自动润色 | 转写文字及处理所需的指令/上下文 |
| 选区改写 | 选中文字、改写指令及该功能使用的上下文 |
| 服务测试 | 固定测试句，或生成的一秒静音音频 |

服务商的数据政策、可用性与计费由服务商决定。转写 Key 与文本模型 Key 分开管理，不会因为保存其中一个就自动开启另一项功能。系统钥匙串授权与向服务商测试连接是不同操作。

屏幕/邻近文字、词汇或个性化上下文功能可能读取额外信息；不需要时可在设置中关闭。请勿在含有不愿上传的信息的文本上启用云端功能。

## 本机保存的数据

设置使用 `com.voiceflow.mac`；历史、词汇、纠正记录和诊断数据主要在 `~/Library/Application Support/VoiceFlow`。录音是否保存取决于功能和设置，历史中可用的重新转写需要保留音频。诊断文件可能含原始或处理后的文字，不应作为普通附件公开上传。

GUI 保存的 Key 使用 macOS 钥匙串。开发模式也能从环境变量/本地 `.env` 读配置；不要把真实凭据写进仓库、终端录屏或公开 Issue。

## 报告问题

优先提供不含真实信息的合成例句、系统版本、功能开关与错误码。截图请遮住姓名、正文、Key、文件路径等私人信息。不要直接上传整个应用支持目录、完整诊断日志或历史数据库。

公开源码不包括维护者的账号配置、录音、开发日志、真实口述测试集或私有仓库历史。
