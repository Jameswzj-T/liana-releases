# 发布要求

源码可编译与安装包可公开分发是两道检查。

## 源码

- 逐项核对公开文件清单，只包含产品源码、合成测试、文档、图标、已批准公开的演示素材与许可证。
- 不带真实 Key、用户设置、音频、历史、日志或个人开发记录。
- 不把曾含私人资料的仓库及其 Git 历史直接改成公开。
- 离线测试通过，记录实际测试范围；不将模拟测试表述为真机验收。

## 安装包（0.1.0 免费开源发布路线）

沿用本仓库发布 0.1.0，保留 RC3/RC4/RC5/RC6 历史，不覆盖旧版本资产。当前选择不购买苹果开发者会员、不做 Apple 公证：源码和未公证预览包可以公开，必须清楚标注签名及首次打开限制，不冒充 Developer ID 签名、公证或新机器已验收。公证不是本项目开源发布的前置条件，也不承诺未来提供公证版。

- 使用可追溯的源码和锁定依赖，收齐解释器、依赖和模型的许可证/NOTICE。
- 验证包内仅含支持的运行依赖、固定模型与资源，不夹带开发环境或用户数据。
- 当前对每份原生可执行代码和整个 App 做临时签名及严格校验，明确这不是 Developer ID 身份认证或苹果公证。
- 记录首次安装、升级、钥匙串授权、麦克风/辅助功能权限以及退出重开的实际验证范围；未覆盖的检查在预览说明中写清楚。
- 目标 Mac 反馈应覆盖本地听写、可选云端开关、失败时保留文字和光标处输入；付费测试须由测试者知情开启，不将历史设备结果冒充新包验收。
- 提供版本、校验值、已知限制和更新说明。

安装文档只提供苹果的单应用“仍要打开”流程，不要求全局关闭系统安全保护。若以后另行选择 Developer ID 与公证路线，再补充对应签名、公证票据及 Gatekeeper 验证；不将其作为当前免费开源路线的阻断。

## 本地预览包构建

当前预览组装器明确复用一个已经审计过的本地 Liana.app 中的 Python 运行时、模型和第三方许可证；不会从该 App 复制产品源码、旧发布元数据、录音或用户数据。产品源码必须来自当前干净提交，依赖版本与模型 SHA 必须匹配本仓库锁文件。该步骤不下载依赖、不访问 Key，也不启动或覆盖原 App。

```sh
python3.12 scripts/package_preview.py \
  --runtime-app /path/to/trusted/Liana.app \
  --output-dir /path/to/new-release-directory
```

已有输出目录会被拒绝。脚本重新编译外壳、检查搬迁与原生库路径，对新包临时签名，检查 ZIP 和隐私边界，并生成 SHA256SUMS。原始本机审计报告在包外，不作为上传附件。它不是从零下载的完整供应链重建工具；运行时来源必须先独立核对，不能使用来路不明的 App。

声纹修复后的构建清单包含 CAM++ 模型（约 28 MB）。若运行时来源是未带该模型的 RC5，额外传入 `--speaker-model /path/to/verified/campplus.onnx`；仅接受清单中固定摘要的官方文件，不从开发目录隐式寻找或复制声纹登记。新模型许可证从本仓库补入，同时保留原运行环境声明。打包中会用包内 Python 实际执行模型加载、合成信号推理、临时登记与读取检查；此检查不使用麦克风或真实声纹，也不代表真人筛选准确率。缺模型、错误摘要、许可证冲突或检查失败都会停止打包。

须在包外用明确合成的语音完成离线模型检查；目标设备的安装、授权和真实输入结果单独记录，未覆盖则披露限制。打包通过不会自动生成 Git 标签、推送源码或上传 Release。公开 Release 只附安装 ZIP 和校验文件，不上传构建日志、临时测试目录或开发审计报告。
